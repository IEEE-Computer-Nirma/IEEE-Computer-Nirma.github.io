About the Event

What is NovaHack CTF?

NovaHack CTF is a Capture The Flag (CTF) competition organized by the IEEE Computer Society Student Chapter at Nirma University as part of NovaHack 2026 (August 22–23, 2026).

It serves as the official cybersecurity track of the event and is kept open in general after the event as an ongoing practice arena.

Each challenge hides a flag — a secret string in the format flag{...}. Find it, submit it, earn points. No experience needed: every challenge comes with hints and a Python script to guide you.

Rules

  • Flag format is always flag{...}
  • Each challenge has two hints that cost 10 points each
  • No sharing flags with other teams during the event
  • Automated scanners or DDoS against the platform is not allowed
  • All tools (Python, browser DevTools) are permitted
  • Tiebreaker: earliest last correct submission
  • Organizer decisions are final
